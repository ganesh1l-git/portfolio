## 🚀 Getting Started

### 1. Run Locally with Vite
```bash
# Install dependencies (already installed)
npm install

# Start local development server
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
npm run build
```
The compiled, optimized production bundle will be generated in `dist/`.

### 3. Deploy Anywhere
You can deploy this portfolio to:
- **GitHub Pages**: Push the repository and set GitHub Pages root to `dist/` or repository root.
- **Vercel**: Run `vercel` or link your GitHub repo.
- **Netlify**: Drag-and-drop the `dist/` folder or configure build command `npm run build` and publish directory `dist`.
